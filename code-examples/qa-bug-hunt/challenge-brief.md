## What To Test

Test:

- Empty fields
- Short names
- Invalid emails
- Valid emails
- Short passwords
- Valid passwords
- Reset button
- Multiple account creation
- Duplicate accounts

## Goal

Find as many bugs as possible and write them clearly.
