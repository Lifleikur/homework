## What To Test

Test:

- Adding cats
- Empty cat names
- Cat ages
- Duplicate cats
- Feeding cats
- Adopting cats
- Food stock
- Revenue
- Hungry cat count
- Searching
- Filtering
- Sorting
- Multiple actions in a row

Find at least 8 bugs.
