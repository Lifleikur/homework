# How GitHub Works (Very Important)

GitHub only uploads:

* files
* commits

It does NOT upload empty folders.

So every folder should eventually contain:

* markdown files
* notes
* examples
* test cases
* screenshots
* automation examples

# Basic Workflow To Follow

## 1. Download Latest Changes

Before starting work:

```bash
git pull
```

---

## 2. Create or Edit Files

Inside VS Code:

* create new files
* update notes/examples
* save changes

Example:

```plaintext
docs/linkedin-notes.md
```

or:

```plaintext
code-examples/api-test-example.js
```

---

## 3. Check What Changed

```bash
git status
```

---

## 4. Add Changes

```bash
git add .
```

---

## 5. Create A Commit

Example:

```bash
git commit -m "Add API testing notes"
```

Good commit messages:

* Add Cypress examples
* Update LinkedIn roadmap
* Add bug report examples
* Improve README

---

## 6. Upload To GitHub

```bash
git push
```
