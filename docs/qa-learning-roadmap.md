# QA Learning Roadmap

## Current Focus

The goal is not to become a software engineer.

The goal is to strengthen practical QA engineering skills for the UK job market.

---

# Priority Learning Order

## 1. Cypress

Focus on:

* selectors
* assertions
* test structure
* login flows
* UI automation basics

---

## 2. API Testing

Learn:

* GET/POST requests
* status code validation
* authentication testing
* Postman collections
* negative test cases

---

## 3. Git & GitHub

Practice:

* commits
* pull/push workflow
* repository organisation

---

## 4. Basic JavaScript

Enough to:

* understand automation scripts
* modify Cypress tests
* read test logic

---

## 5. Playwright (Later)

Modern automation framework increasingly used in QA roles.

Not urgent initially.

---

# Current Goal

Build a small but professional QA portfolio showing:

* practical testing examples
* documentation
* automation basics
* structured QA thinking
